Reaction game

Tap the band to start a round. Its light turns red: wait. When it turns green, tap as fast as you can. The best time is saved on the band itself.

Connect does nothing? This page was opened as a file (by double-click), so the browser blocks its program. Open it through the web server on your own computer: in a terminal, in your project folder (my-project, the folder that holds vexo-open-kit), run python3 -m http.server 8000 --bind 127.0.0.1 (on Windows type python), then open http://localhost:8000/vexo-open-kit/projects/reaction-game/ (8000, or the port you started it with) in Chrome or Edge. Copied this page into your own folder? The command is the same; open http://localhost:8000/reaction-game/.

Double-tap your band, type its number and press Connect. No band? Choose "Pretend band".
