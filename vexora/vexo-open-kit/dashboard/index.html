Nothing on this page works? It was opened as a file (by double-click), so the browser blocks its program. Open it through the web server on your own computer: in a terminal, in your project folder (the folder that holds vexo-open-kit), run python3 -m http.server 8000 --bind 127.0.0.1 (on Windows type python). Then type localhost:8000/vexo-open-kit/dashboard/ (8000, or the port you started it with) in the address bar of Chrome or Edge.

Which band?

  1. Double-tap your band to wake it up.
  2. Press Connect and pick your band from the list.
  3. Watch the band flash.

By USB cable: the browser shows a list of every port on this computer, not only bands. Pick Vexo Open band. Its port is called cu.usbmodem… on a Mac, COM and a number on Windows (there the name can be "USB Serial Device"), ttyACM… on Linux. Not "Bluetooth-Incoming-Port" and not "debug-console". No band in the list? Try another cable: some only charge.

Microphone

Loudness

Audio is off.

Both switches turn the microphone on. While it is on, the band shows a solid blue light and the LED controls are locked. Loudness meter sends only how loud it is. Stream audio makes the band send compressed sound (Opus). This page counts it; it is played or turned into text only if you switch on Listen or Live transcript below. The sound is not saved. It is not sent anywhere either, unless you switch on Live transcript below: that sends it to Deepgram, a speech-to-text company.
