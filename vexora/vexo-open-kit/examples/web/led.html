LED

Set the colour of the band's light.

Double-tap your band, then press Connect and pick it from the list. No band? Tick "Pretend band".

Connect does nothing? This page was opened as a file (by double-click), so the browser blocks its program. Open it through the web server on your own computer: in a terminal, in your project folder (the folder that holds vexo-open-kit), run python3 -m http.server 8000 --bind 127.0.0.1 (on Windows type python), then open http://localhost:8000/vexo-open-kit/examples/web/led.html (8000, or the port you started it with) in Chrome or Edge.

The pretend band's light is off.
